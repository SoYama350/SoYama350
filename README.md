## Featured Projects

### 🧠 [AI Task Supervisor](https://github.com/SoYama350/ai-task-supervisor-mvp)
An AI workflow orchestrator that turns messy to-do lists into a prioritized, actionable
daily plan. It parses natural-language tasks, places them on the **Eisenhower Matrix**,
and generates an ordered execution plan.
- **Stack:** Next.js 14 (App Router), TypeScript, Supabase, Vercel AI SDK + OpenAI, PostHog, Vitest
- **Highlights:** feature-flagged AI features, token-usage tracking with per-user quotas,
  admin dashboard, CSAT micro-survey, and a 90-day "sustainability kill-switch".
- Written against a full [`requirements.md`](https://github.com/SoYama350/ai-task-supervisor-mvp/blob/main/requirements.md) spec, with unit tests.

### 📈 [AEO.ai](https://github.com/SoYama350/aeo-ai) · [Live demo →](https://my-business-opencode.vercel.app)
An "Answer Engine Optimization" SaaS that scores content for AI-search citation
readiness and gives improvement recommendations.
- **Stack:** Next.js, NextAuth, Supabase (Postgres + RLS), OpenRouter, Lemon Squeezy payments
- **Highlights:** freemium tier with daily usage limits, subscription tiers, AI analysis API,
  Supabase migrations + RLS policies.

### 🎮 [Forge Gaming — Capstone](https://github.com/SoYama350/Capstone)
A gaming web application capstone built with React + Vite + TypeScript.
- **Stack:** React 19, React Router 7, Vite, Oxlint
