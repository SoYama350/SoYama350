## 🤖 How I work with AI

AI is my pair-programmer, not my author. Concretely:

- **I use AI for structure and boilerplate** — scaffolding, form schemas, API glue, first-draft copy. It turns a 30-minute task into 5 minutes.
- **I review every diff like it was written by a stranger** — I read what it generated before merging, and I run the test suite rather than trusting the green checkmark.
- **I own the judgment calls** — model choice, schema shape, cost guardrails, and *when not to use AI*in the first place. The [`FE-03-AI-workflow-drill`](https://github.com/SoYama350/FE-03-AI-workflow-drill) repo documents a full case study of me catching (and fixing) AI mistakes — including where a precise prompt beat a vague one 4× in end-to-end time.



> **Why this matters:** most 2026 interviews and hiring teams ask variants of: *"What would you change about an AI-generated solution and why?"* Every repo above contains a concrete answer.
